Connect your chat

Chat needs a Supabase project before accounts and live messages can be enabled.

  1. Create a Supabase project and copy its project URL and public anon key.
  2. Set KILLBYTE_SUPABASE_URL and KILLBYTE_SUPABASE_ANON_KEY in chat-config.js.
  3. Download the chat SQL and run it in the Supabase SQL Editor.
  4. Enable Realtime for public.chat_messages using the setup guide.
